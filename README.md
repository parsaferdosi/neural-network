# شبکه عصبی

## معرفی

این مخزن شامل یک شبکه عصبی ساده است که از ابتدا با استفاده از کتابخانه NumPy پیاده‌سازی شده است. هدف این پروژه، یادگیری و آزمایش مفاهیم پایه‌ای یادگیری عمیق است. در حال حاضر، این مدل داده‌های تستی ذخیره‌شده در فایل شبکه عصبی را پردازش کرده و یاد می‌گیرد و ذخیره میکند.

## ویژگی‌ها

- **پیاده‌سازی کامل با NumPy**: بدون استفاده از کتابخانه‌های یادگیری عمیق مانند TensorFlow یا PyTorch.
- **سه بخش اصلی**:
  - `neuron.py`: پیاده‌سازی نورون‌ها همراه با وزن‌ها، بایاس و توابع فعال‌سازی.
  - `layers.py`: مدیریت چندین نورون در قالب یک لایه.
  - `network.py`: ترکیب چندین لایه برای تشکیل شبکه عصبی کامل.
  - `test.pu`:برای آزمایش شبکه پس از آموزش
  - `train.py`:برای آموزش دادن شبکه بر اساس mnist
  - `memmoryCore.npz`:بخش حافظه شبکه که وظیفه حفظ یادگیری را دارد
- **توابع فعال‌سازی**: از **Sigmoid** و **ReLU** برای یادگیری استفاده می‌کند.
- استفاده از تابع **softmax** برای اطمینان از خروجی شبکه در کلاس لایه ها
- **توانایی یادگیری اولیه**: این مدل در حال حاضر داده‌های تستی را پردازش کرده و از آن‌ها یاد می‌گیرد.
- **ذخیره و بازیابی وزن‌ها**: امکان ذخیره و بارگذاری وزن‌های آموزش‌دیده‌شده برای استفاده مجدد.

## ساختار پروژه

```
├── neuron.py       # پیاده‌سازی نورون‌های منفرد
├── layers.py       # مدیریت چندین نورون در قالب لایه‌ها
├── network.py      # شبکه عصبی شامل چندین لایه
├── memmoryCore.npz #بخش حافظه که یادگیری پیشفرضی که انجام دادم داخلشه
├── test.py         #برای تست شبکه عصبی و تخمین درصد خطای آن
├──train.py         #وظیفه تمرین شبکه
├── README.md       # مستندات پروژه
```

## نصب

برای دریافت مخزن و نصب وابستگی‌ها، از دستورات زیر استفاده کنید: 

```sh
git clone https://github.com/parsaferdosi/neural-network.git
cd neural-network
pip install numpy
```

## استفاده

### اجرای شبکه عصبی

برای اجرای شبکه ابتدا فایل rar داخل پوشه mnist_data را اکسترکت کرده و سپس برای تمرین دادن مجدد مدل دستور زیر را استفاده کنید:

```sh
python train.py
```
این عملیات ورودی‌های mnist_train را پردازش کرده و مدل را آموزش می‌دهد.

و برای تست مدل:
```sh
python test.py
```


## برنامه‌های آینده

- تطبیق شبکه عصبی برای کاربردهای **OCR (تشخیص نویسه‌های نوری)**

- آموزش مدل روی **داده‌های واقعی** به‌جای ورودی‌های تستی
- بررسی **معماری‌های مختلف** برای بهبود عملکرد مدل
